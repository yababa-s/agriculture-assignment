# Basic Statistics Hindi examples

`decoder_train.jsonl` uses three short Kruti Dev labels present in the supplied 2023–24 Basic Statistics PDF. `decoder_test.jsonl` uses two labels from the supplied 2024–25 Basic Statistics PDF. The split is by source document.

These examples are for developing and checking the deterministic decoder. They are **not** examples used to fine-tune a language model, and this project does not claim that an LLM was trained. The evaluation checks the output of the decoder directly.
