## 2. Fine-tuning ladder on the same held-out cases (`scripts/eval_llm_tasks.py`)

| Metric | Base zero-shot | Base 2-shot prompt | + LoRA v1 | + LoRA v2 |
|---|---|---|---|---|

| Column mapping accuracy (n=74) | 0.027 | 0.23 | 0.635 | 0.595 |
| Routing, model only (20 files) | 0.4 | — | 0.0 | 0.35 |
| Routing valid-id rate | 1.0 | — | 0.2 | 0.85 |

**Reading.** The adapter adds a lot over prompting on the tasks it was trained for: island F1 0.594 → 0.935, columns 0.230 → 0.635. It is also faster than the long 2-shot prompt (10.4 s vs 17.9 s per island). Adapter v1 forgot tasks outside its training (routing). v2 adds planning and routing examples. It keeps the extraction gain (0.914), repairs JSON validity (0.61 → 0.84) and the valid-id rate (0.2 → 0.85), but routes held-out files correctly only 2/14 times (base 7/14). Deployment therefore keeps hybrid rules-first routing (0.95). Extraction uses v1 and query planning uses v2.

### 3b. Robustness (`--set robust_dev` / `--set robust_test`)

The first query agent had no way to decline a question: every input became a query, so "hi my name is …" returned a farmer count. The scope layer (`agri/query/scope.py` plus plan grounding) refuses chit-chat and concepts the knowledge base does not hold, explains unsupported ranking of crops, answers "why / should I" questions with facts only, and maps everyday wording and relative time.

| Set | Rules | Deployed hybrid |
|---|---|---|
| robustness dev (n = 14, used to build the fixes) | 1.00 | 1.00 |
| **robustness test (n = 15, written afterwards, run once)** | **0.73** | **0.87** |

The two hybrid misses on the test set (number words such as "two years"; comparing two items' prices for a year) were fixed afterwards and are not re-measured on fresh data. Dev and the original test sets did not regress (hybrid: 1.00 and 0.93).

A 97-question coverage battery was then written (`data/gold/queries_battery.json`, `scripts/query_battery.py`) and a corpus audit was run (`scripts/audit_db.py`). The battery covers every measure, level, time form, everyday wording, Hindi and off-topic questions. Both are described in [data_quality.md](data_quality.md).

## 5. Errors in the source publications (kept and flagged, not corrected)

* **D10** (Island-wise Statistical Outline 2024-25), p. 9: Shaheed Dweep *Farmers-516*. This is Swaraj Dweep's figure; the 2022-23 and 2023-24 editions print 317.
* **D11** (price statements 2023): November-2023 onion is 81.88 on p. 23 and 57.50 on p. 24. D12 and D13 print 81.88. `v_conflict` lists the pair. The query agent uses 57.50, the value consistent with October and December 2023, and its answer names both values.
* **D13** (price statements 2025): eggs in September 2025 are 30.00 on p. 9 and 90.00 on p. 10. The months around it are 84–108, so answers use 90 and flag 30.
* **D06** (Basic Statistics 2024-25), p. 3: fertilizer use in 2024-25 is Nitrogenous 6.88 t and Potassic 3,265.5 t, against 137 t and 32 t a year earlier. This is printed so (checked against the PDF text) and is kept.
